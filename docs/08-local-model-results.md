# 로컬 모델 연결 및 테스트 결과

## 서버 실행

기존 서버를 중지한 후 프로젝트 폴더에서 실행합니다.

```powershell
.\.venv-train\Scripts\python.exe -m uvicorn main:app --reload
```

현재 기본 인식 경로는 `runs/detect/ozm_augmented/weights/best.pt`이며 CUDA GPU 0을 사용합니다.
아래 평가 표는 이전 baseline 모델의 기록입니다. 증강 모델 비교 결과는
`runs/evaluation_augmented/comparison.md`를 참고하세요.
API 키 없이 로컬로 추론합니다. CPU 실행은 `YOLO_DEVICE=cpu` 환경변수로 선택합니다.
`uv run uvicorn`은 GPU 학습 라이브러리가 없는 기존 환경을 사용할 수 있으므로 위 명령을 사용하세요.
`DETECTION_BACKEND=roboflow`를 지정하면 기존 클라우드 경로를 사용할 수 있으며,
그 환경에는 inference-sdk와 ROBOFLOW_API_KEY가 필요합니다.

`/detect`는 신뢰도 0.25 이상 결과를 반환하고 프런트엔드는 기존 0.70·1초 자동 등록 조건을 적용합니다.
같은 클래스 중 최고 신뢰도 표시와 재등록 조건도 유지합니다. `l_onion`은 대파에 연결했습니다.

## 평가 조건

- 테스트 분할 78장, 정답 박스 219개
- 모델: 102에포크에서 저장된 best.pt
- 이미지 크기 640, NMS IoU 0.7
- 고정 신뢰도 0.70, 정답 매칭 IoU 0.50에서 micro Precision/Recall/F1 산출
- AP는 별도로 conf=0.001부터 계산한 클래스 평균. 고정 0.70에서 잘린 AP가 아님
- 테스트 결과를 보고 임계값을 변경하지 않았음

100%인 클래스도 표본이 작아 실환경 무오탐을 의미하지 않습니다.
사과·마늘이 FP 35개 중 25개를 차지하므로 라벨 누락·중복 박스·혼동 배경을 우선 점검하세요.
정밀도 우선 임계값 조정은 검증 분할에서 선택하고 별도 데이터로 다시 확인해야 합니다.
이 수치는 정지 이미지의 객체 탐지 성능이며 1초 유지 조건을 포함한 장바구니 등록 정확도가 아닙니다.
검증 분할 mAP50=87.1%, mAP50-95=73.0%와 테스트 결과는 데이터가 다르므로 구분해야 합니다.
