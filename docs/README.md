## 현재 구현 범위

- FastAPI 서버 및 SQLite/SQLAlchemy 연동
- 상품 10종과 가격 관리
- 장바구니 추가, 감소, 조회, 초기화 및 총액 계산
- 재료 종류와 필요 수량을 반영한 요리 추천
- 레시피 재료 수량과 단계별 요리 방법 조회
- React 카메라 미리보기, 장바구니, 추천 결과 및 레시피 모달
- YOLO 연결 전 개발용 상품 인식 테스트

## 향후 구현 범위

- 학습된 YOLO 모델 연결
- 탐지 클래스명을 상품명으로 변환
- 동일 상품 연속 탐지 방지
- 실제 카메라 환경 통합 테스트 및 시연 최적화
