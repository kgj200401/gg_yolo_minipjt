## 이동한 내용

- 루트의 학습·평가·증강·분석 Python 스크립트 22개를 `experiments/`에 모았다.
- 루트 및 `runs/`에 흩어진 로그·과거 PID 기록 30개를 `runs/logs/`에 모았다. PID는 과거 기록이다.

- 데이터 YAML·과거 학습 args의 절대경로와 서비스 참조를 보존하기 위해 `dataset*/`, `runs/detect/`, 사전학습 `.pt` 위치는 유지했다.

## 경로 수정

이동한 스크립트의 `Path(__file__)` 기준 루트를 상위 프로젝트 폴더로 수정했다. 실험 러너가 호출하는 하위 스크립트 경로를 `experiments/파일명.py`로 바꾸고, docs의 실행 명령·로그 경로도 갱신했다. 형제 모듈 import는 직접 `.py` 실행 방식에서 정상 작동한다.

`prepare_label_review.py`에는 main 가드를 추가해 다른 코드가 import할 때 검토 이미지가 자동 생성되지 않도록 했다.

현재 명령 예시(프로젝트 루트에서 실행):

```powershell
.\.venv-train\Scripts\python.exe experiments/train_model.py --help
.\.venv-train\Scripts\python.exe experiments/evaluate_class_thresholds.py
Get-Content runs/logs/capacity_training.log -Encoding UTF8 -Tail 10
```
