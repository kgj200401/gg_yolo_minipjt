# 와이어프레임

## 1. 쇼핑 메인 화면 — 데스크톱/카트 태블릿

```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ [🛒] AI 스마트 카트                              [● 서버 연결됨]          │
│      Smart Shopping Assistant                                             │
├──────────────────────────────────────────────┬──────────────────────────────┤
│ LIVE DETECTION                 [YOLO 연결 예정]│ MY CART                  [3]│
│ 상품 인식                                    │ 현재 장바구니                │
│                                              ├──────────────────────────────┤
│ ┌──────────────────────────────────────────┐ │ [🥩] 고기  8,000원  [-]1[+] │
│ │ ┌─                                      ─┐ │                      8,000원 │
│ │                                          │ │ [🧅] 양파  2,000원  [-]1[+] │
│ │              실시간 카메라               │ │                      2,000원 │
│ │                                          │ │ [🌿] 대파  2,000원  [-]1[+] │
│ │          [● 인식 대기 중]                │ │                      2,000원 │
│ │                                          │ │                              │
│ │ └─                                      ─┘ │                              │
│ │                            [카메라 끄기] │ │                              │
│ └──────────────────────────────────────────┘ ├──────────────────────────────┤
│                                              │ 전체 상품 수              3개 │
│ ▸ YOLO 연결 전 인식 테스트                   │ 총 구매금액          12,000원 │
│                                              │ ┌──────────────────────────┐ │
│                                              │ │ 구매 완료 · 요리 추천 보기│ │
│                                              │ └──────────────────────────┘ │
└──────────────────────────────────────────────┴──────────────────────────────┘
```

### 레이아웃 기준

- 전체 최대 너비: 1,240px
- 좌측 카메라와 우측 장바구니 비율: 가변 영역 + 400px
- 카메라 최소 높이: 550px
- 상품 카드 그리드는 사용하지 않는다.
- YOLO 연결 전 테스트 입력은 기본적으로 접힌 상태로 둔다.
- 장바구니는 내용이 많아지면 내부 스크롤을 사용한다.

## 5. 레시피 상세 모달

```text
                 ┌─────────────────────────────────────────────┐
                 │ [🥧] RECIPE GUIDE                     [×]   │
                 │      사과파이                               │
                 ├─────────────────────────────────────────────┤
                 │ 필요한 재료                                 │
                 │ ┌──────────────────┐ ┌──────────────────┐   │
                 │ │ 🍎 사과      1개 │ │ 🍞 식빵      2장 │   │
                 │ └──────────────────┘ └──────────────────┘   │
                 │ ┌──────────────────┐                        │
                 │ │ 🥚 계란      1개 │                        │
                 │ └──────────────────┘                        │
                 │                                             │
                 │ 요리 방법                                   │
                 │ [1] 사과를 작게 썰어 설탕과 볶습니다.       │
                 │ [2] 식빵 가장자리를 자르고 얇게 누릅니다.   │
                 │ [3] 볶은 사과를 넣고 식빵을 접습니다.       │
                 │ [4] 달걀물을 바르고 노릇하게 굽습니다.      │
                 └─────────────────────────────────────────────┘
```

### 모달 동작

- `요리법 보기` 버튼으로 연다.
- 배경 영역, 우측 상단 닫기 버튼 또는 `Esc` 키로 닫는다.
- 화면 높이를 넘으면 모달 내부만 스크롤한다.

```text
┌──────────────────────────────┐
│ [🛒] AI 스마트 카트 [● 연결]│
├──────────────────────────────┤
│ 상품 인식                    │
│ ┌──────────────────────────┐ │
│ │                          │ │
│ │       카메라 화면        │ │
│ │                          │ │
│ └──────────────────────────┘ │
│ ▸ YOLO 연결 전 인식 테스트  │
├──────────────────────────────┤
│ 현재 장바구니             [2]│
│ [🍎] 사과   2,500원 [-]1[+]│
│ [🍞] 식빵   3,500원 [-]2[+]│
│ 총 구매금액          9,500원│
│ [구매 완료 · 요리 추천 보기]│
└──────────────────────────────┘
```

- 960px 이하에서는 카메라와 장바구니를 1열로 배치한다.
- 640px 이하에서는 추천 카드와 상세 재료도 1열로 배치한다.
